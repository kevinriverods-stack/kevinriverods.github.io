# Data Science & Analytics Portfolio

Bilingual (Spanish / English), responsive portfolio website built with plain HTML, CSS and JavaScript. Designed for GitHub Pages.

## 1. Personalise before publishing

Open `index.html` and `assets/js/main.js` and update:

- The email address in the contact button (`TU_CORREO@ejemplo.com`).
- The professional bio so it accurately reflects your experience.
- The services and technologies you can confidently deliver.
- Project descriptions and links as each project is completed.

Do not claim client work, results, certifications or tools you have not actually used. The three project cards are clearly marked as in development.

## 2. Preview locally

You can open `index.html` in your browser. For a local server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## 3. Publish with GitHub Pages

1. Create a GitHub repository named `your-github-username.github.io`.
2. Upload all files and folders from this project (keep the `assets` folder structure).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment and open `https://your-github-username.github.io`.

If you use a repository with another name, the URL will usually be `https://your-github-username.github.io/repository-name/`.

## 4. Suggested repository structure

```text
your-github-username.github.io/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── styles.css
    └── js/
        └── main.js
```
